# Как запустить сайт «Блок·Ноль»

## Что уже готово
- `index.html`, `articles/*.html` — сам сайт (просто открой `index.html` в браузере, чтобы посмотреть)
- `assets/style.css` — стили
- `articles.json` — база всех статей (3 готовые статьи внутри)
- `build.py` — пересобирает HTML-страницы из `articles.json`
- `generate_article.py` — пишет новую статью через нейросеть и добавляет её в `articles.json`
- `.github/workflows/publish.yml` — расписание автопубликации

## Шаг 1. Разместить сайт на GitHub Pages (бесплатно)

1. Зарегистрируйся на [github.com](https://github.com), если ещё нет аккаунта.
2. Создай новый репозиторий (кнопка **New repository**), например `blok-nol`. Сделай его **Public**.
3. Загрузи туда все файлы из этой папки (можно через веб-интерфейс: **Add file → Upload files**, перетащить всё содержимое).
4. Зайди в **Settings → Pages**, в разделе **Source** выбери ветку `main` и папку `/ (root)`, сохрани.
5. Через пару минут сайт будет доступен по адресу вида `https://твой-логин.github.io/blok-nol/`.

## Шаг 2. Подключить свой домен (если используешь REG.RU)

В настройках домена на REG.RU добавь DNS-записи, которые укажет GitHub в разделе **Settings → Pages → Custom domain** после того, как ты впишешь туда свой домен. GitHub сам покажет точные значения записей — просто следуй подсказкам на этой странице.

## Шаг 3. Получить ключ для автогенерации статей

1. Зайди на [console.anthropic.com](https://console.anthropic.com), зарегистрируйся.
2. Пополни баланс — генерация одной статьи стоит копейки (обычно меньше 5 ₽).
3. В разделе **API Keys** создай новый ключ, скопируй его (он показывается один раз).

## Шаг 4. Добавить ключ в GitHub (чтобы он не был виден в коде)

1. В репозитории зайди в **Settings → Secrets and variables → Actions**.
2. Нажми **New repository secret**.
3. Имя: `ANTHROPIC_API_KEY`, значение — вставь ключ из шага 3.
4. Сохрани.

## Шаг 5. Проверить автопубликацию

Расписание уже настроено на каждый день в 07:00 по Москве (файл `publish.yml`). Чтобы проверить сразу, не дожидаясь завтра:

1. Зайди во вкладку **Actions** в репозитории.
2. Слева выбери **Автопубликация статьи**.
3. Справа нажми **Run workflow → Run workflow**.
4. Через минуту-две обнови страницу — если всё сработало, в `articles.json` появится новая статья, а сайт обновится.

## Как добавить новые темы для генерации

Открой `generate_article.py`, найди список `TOPICS` в начале файла и добавь туда новые темы в том же формате:

```python
{
    "title": "Название новой темы",
    "type": "lesson",   # или "review" для обзоров
    "tags": ["тег1", "тег2"],
},
```

Скрипт сам выберет из списка ещё неиспользованную тему при следующем запуске.

## Как заполнить реальную партнёрскую ссылку

Открой `articles.json`, найди статью `kak-vybrat-birzhu`, в поле `"affiliate"` замени:
- `"name"` — реальное название биржи
- `"url"` — свою реферальную ссылку
- `"note"` и `"cta"` — текст под свою программу

После правки запусти `python3 build.py`, чтобы пересобрать HTML, и загрузи изменения на GitHub (или просто отредактируй `articles.json` прямо на GitHub в браузере — тогда `build.py` можно запускать локально и заливать только готовые HTML-файлы).

## Telegram-канал

Создай канал в Telegram, замени во всех файлах `https://t.me/your_channel` и `@your_channel` на свою реальную ссылку и юзернейм (быстрее всего — через поиск и замену в `templates/base.html` и `templates/index.html`, затем `python3 build.py`).

## Важно про безопасность и честность контента

- Не убирай дисклеймеры внизу страниц — они не декоративные, а снижают юридические риски и защищают читателей.
- Не переписывай промпт в `generate_article.py` так, чтобы он поощрял обещания дохода или конкретные прогнозы цен — это может ввести людей в заблуждение и приведёт к проблемам с рекламными и партнёрскими программами.
- Периодически всё же читай сгенерированные статьи сам — раз в неделю пробежаться глазами гораздо надёжнее, чем полностью довериться автоматике.
